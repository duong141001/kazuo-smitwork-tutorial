3 Tiêu chí "đủ điều kiện" (Definition of Ready cho QA)

Build/tính năng phải đạt các mục sau ở bước staging thì QA mới nhận test sâu. Tiêu chí cốt lõi là đủ module như game gốc:

  • Đủ module như game gốc — đối chiếu từng thành phần của tính năng với bản gốc, không thiếu module nào (vd Túi đồ: xếp/gộp đồ, khóa an toàn, phân loại, mở rộng ô, tooltip item...).
  • Có bảng đối chiếu module gốc (checklist các module bản gốc) để QA so từng mục.
  • Tính năng chạy được trên staging, không crash khi mở.
  • Luồng chính (happy path) đi hết được từ đầu tới cuối.
  • Không có lỗi chặn (blocker) khiến không test tiếp được.
  • Có mô tả tính năng / GDD để QA biết "đúng" là thế nào.
  • Dev đã tự test qua và ghi chú phần chưa hoàn thiện (nếu có).
Lưu ý quan trọng — "Đủ" ở đây nghĩa là đủ so với game gốc, không phải "chạy là được". Một tính năng có thể mở lên không crash nhưng vẫn thiếu module so với bản gốc — trường hợp này QA đánh dấu chưa đủ và ghi rõ module còn thiếu để Dev bổ sung.

4 Đầu vào / Đầu ra của QA với các team

QA không làm việc một mình. Để test được, mỗi team phải bàn giao "đầu vào"; test xong, QA trả "đầu ra" về đúng team đó.

QA cần gì từ các team (đầu vào)

TeamPhải cung cấp cho QA
Game DesignTài liệu GDD (mô tả tính năng, luật chơi) + Figma (thiết kế UI/UX) + bảng đối chiếu module game gốc
DevBản build chạy được trên staging + ghi chú tính năng đã xong / chưa xong + môi trường/tài khoản test
Art / AssetBộ asset chuẩn (icon, hiệu ứng, model 3D) để đối chiếu hiển thị trong game
PM / POĐộ ưu tiên tính năng + tiêu chí nghiệm thu (Definition of Done) cho từng story

QA trả gì về các team (đầu ra)

Gửi cho teamQA bàn giao
DevBug report (mô tả lỗi, bước tái hiện, severity) trên Kazuo + danh sách module còn thiếu so với game gốc + xác nhận retest đạt
Game DesignĐối chiếu GDD ↔ thực tế: chỗ nào game làm khác/thiếu so với thiết kế; phản hồi tính hợp lý khi chơi thật
Art / AssetLỗi hiển thị: asset sai, vỡ hình, hiệu ứng/animation lệch so với bản chuẩn
PM / POBáo cáo chất lượng: tỉ lệ pass/fail, tính năng nào đạt release, rủi ro còn lại
